# Home Assistant Add-on: Audiobookshelf

Audiobookshelf is a self-hosted audiobook and podcast server.

## Features
- Fully featured Web UI and REST API
- Android & iOS mobile apps support
- Multi-user support with custom permissions
- Real-time progress sync
- Automatic metadata fetching and chapter support

## Configuration & Access
- **Web UI Port**: Access the web interface at `http://<home-assistant-ip>:13378`
- **Config & Database**: Stored in `/config` (persisted in Home Assistant storage)
- **Metadata**: Stored in `/config/metadata`
- **Audiobooks & Podcasts**: Map your media folders under Home Assistant's `/media` or `/share` directories.
